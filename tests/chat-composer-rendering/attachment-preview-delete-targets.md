# 手机附件预览与删除热区分离

## 前置条件
- 使用隔离验收服务，准备两张可丢弃测试图片。
- 分别检查 375×812、768×1024、桌面尺寸，以及浅色和深色主题。

## 操作
1. 在输入框上传两张图片，检查预览按钮和删除按钮的边界框不重叠。
2. 点击第一张图片中心和边缘，打开大图；关闭预览后附件数量仍为两张。
3. 点击图片外侧的删除按钮，只移除对应图片，且不会打开预览。
4. 通过键盘聚焦两个按钮，分别触发预览和删除。

## 预期
- 预览与删除的点击区域互不覆盖，删除热区至少 44×44 CSS px。
- 多图不相互遮挡；暗色主题的预览边框和删除按钮可辨认。
- 点击预览或删除不发送消息、不新增 RPC 请求。

## 清理
- 移除测试附件或关闭测试标签页；不删除用户聊天。

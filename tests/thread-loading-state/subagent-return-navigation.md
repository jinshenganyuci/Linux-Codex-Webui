# 子任务对话左上角返回入口

## 前置条件

使用独立 13511 验收地址；保留现有会话、配置和任务。验收脚本复用三个已完成的测试会话，通过浏览器响应回放模拟子任务关系及运行状态，不发送真实任务。

## 操作步骤

1. 在父对话展开状态卡详情，点击“打开子线程”；检查子任务页左上角出现灰色返回入口。
2. 点击返回，应回到刚才的父对话。再展开聊天中的“子任务活动”，点击“打开子任务对话”，确认入口行为一致。
3. 从子任务打开其子任务，连续点击左上角返回，依次回到子任务和根对话，根对话不再显示该入口。
4. 进入子任务后刷新，再点击返回；复制带来源参数的子任务链接到新标签页，确认没有浏览器历史也能返回父对话。
5. 从普通会话链接或侧栏进入其他会话，不应继承上一次子任务的返回目标。子任务不在侧栏列表时，标题应显示“子任务对话”，而不是“选择一个线程”。
6. 在 1440×900、375×812、768×1024 各测试明暗主题：桌面显示左箭头和“返回”，手机显示 44px 点击区域的左箭头；不得挤掉标题、遮挡现有菜单或产生横向溢出。手机子任务顶栏暂不显示新建图标，仍可通过侧栏新建；普通对话顶栏不变。键盘 Tab 可聚焦并激活入口。

## 性能与清理

返回关系保存在链接的 `from` 参数中，最多 16 层；不读写全局偏好，不调用额外的父线程查询、不扫描历史或轮询。导航继续使用原线程加载和缓存路径；记录每一步的原有 RPC 请求以检查重复加载。关闭验收浏览器即清理回放数据，真实会话与配置不变。仅需静态更新 13511；回退时从目标提交重新构建前端，既有不带来源参数的链接继续有效。

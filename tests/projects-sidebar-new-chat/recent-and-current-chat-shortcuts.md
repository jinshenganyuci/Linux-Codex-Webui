# 最近与当前对话快捷入口

## 前置条件

- 侧栏至少有两个项目，以及项目内和无项目的多条对话；准备一条时间较早但当前正在查看的对话。
- 浅色和深色主题均可使用；有一条置顶对话与至少一条未置顶对话。

## 操作

1. 打开侧栏，保持项目原有展开和顺序，查看“最近对话”区。
2. 进入一条较早的未置顶对话，观察该区首行、项目标签和原项目标题。
3. 返回新聊天，确认“最近对话”按更新时间显示最近五条未置顶对话。
4. 置顶一条近期对话，确认它仅在“已置顶”区，不重复占用最近五条；输入搜索词，确认搜索结果不会重复显示快捷入口。
5. 在浅色、深色和窄屏下检查当前标识、标题截断、项目标签及点击导航。

## 预期结果

- 当前未置顶对话始终位于快捷入口首行并显示“当前”；其余行按更新时间排列，最多五行。
- “已置顶”保持在“最近对话”之前；“聊天”和“项目”仍位于其后。
- 快捷入口跨项目展示，不改项目的手动排序、折叠状态或原始线程列表；当前项目标题有可辨识的强调。
- 点击快捷入口与点击原线程行打开相同对话；搜索和置顶状态不会产生重复结果。
- 浅色与深色背景、文字对比正常；窄屏无横向溢出。

## 回滚与清理

- 恢复测试前的主题和置顶状态；不需要修改项目顺序或删除对话。

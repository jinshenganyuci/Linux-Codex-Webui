# ChatGPT 桌面风格预览与两端布局

## 功能与前置条件

以用户提供的六张桌面截图为视觉基准，统一中性灰主题、侧栏、首页任务卡、聊天列、输入框及原生设置浮层。
在 13511 验收端运行本次前端构建；保留后端与 CODEX_HOME，使用独立预览会话。视口 1440×1000、768×1024、375×812，各检查浅色和深色。

## 精确操作与预期

1. 打开首页，点击四张任务卡之一：文字填入草稿，不自动发送；浅灰侧栏、实色主区域、细边框与黑白发送按钮一致。手机任务卡排为两列。
2. 打开有消息的会话：比较助手消息、命令行、等待状态、队列和输入框的左右边界，坐标差不超过 1 CSS px；扣除侧栏后，两侧留白相等。
3. 检查短聊天与长命令：短消息按内容宽度呈现，长命令保留展开能力，等待卡不再贴屏幕左边。消息增多时不插入固定大块空白。
4. 打开模型、添加、权限及会话控制：菜单完整处于视口内；明暗主题均无错误浅色底；等待 2–3 秒后截取真实改变的区域。
5. 会话控制按 [原生控制用例](../chat-composer-rendering/native-thread-controls.md) 检查外部关闭、Esc、草稿保留及子菜单。
6. 手机打开侧栏并操作会话菜单：原有点击入口保持可达。手机模型、权限与推理仍在一个设置 Sheet 中呈现。
7. 手动调出手机软键盘，检查目标输入框、内部滚动、底部安全区；键盘关闭后面板恢复。桌面视口模拟不替代真实软键盘验收。
8. 刷新页面，确认仍加载预览构建；打开扩展页并返回会话，面板样式一致。

## 自动验收命令

先 `pnpm run build`，然后运行：

```bash
UI_PREVIEW_THREAD_ID=<独立预览会话ID> node scripts/verify-chatgpt-preview.cjs
UI_PREVIEW_THREAD_ID=<独立预览会话ID> node scripts/verify-chatgpt-preview-runtime.cjs
```

默认在 13511 上拦截静态资源为当前 dist；runtime 脚本仅在浏览器拦截历史与队列夹具，队列写操作不进入真实 CLI。正式替换预览前端后，使用 `LIVE_PREVIEW=1` 再跑第一个脚本，验证真实服务资产。证据位于 `output/playwright/chatgpt-preview/`。
